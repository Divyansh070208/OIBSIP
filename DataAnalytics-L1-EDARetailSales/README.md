# Level 1 - Task 1: Exploratory Data Analysis (EDA) on Retail Sales Data

## 📌 Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on retail sales transactions to identify seasonal trends, demographic spending patterns, and high-performing product categories.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## 🔍 Key Insights
1. **Demographic Concentration:** Customers aged 26–50 generate the highest cumulative basket values across high-margin categories (Electronics and Home & Kitchen).
2. **Seasonality:** Quarterly demand surges reveal distinct seasonal cycles requiring proactive inventory ramp-up.
3. **Product Performance:** Top 10 revenue-generating products account for a disproportionate share of total revenue.

## 💡 Business Recommendations
1. **Targeted Campaigns:** Focus high-ticket promotions on the 26–50 demographic.
2. **Stock Optimization:** Increase buffer inventory by 20% prior to peak quarters.
3. **Cross-Selling:** Bundle high-frequency apparel and beauty items with electronics to boost Average Order Value (AOV).
